# Operations SLA & Performance Analytics

## Project Overview
An end-to-end Operations Analytics project focused on analyzing task performance, SLA compliance, operational efficiency, and workload distribution.

The project demonstrates how operational data can be transformed into actionable business insights using Excel, SQL, and Power BI.

## Business Objectives
- Monitor overall task performance and completion rates.
- Identify SLA breaches and operational bottlenecks.
- Analyze workload distribution across teams.
- Evaluate performance across task priority levels.
- Identify opportunities to improve operational efficiency.

## Tools & Technologies
- Microsoft Excel – Data cleaning, KPI calculations, Pivot Tables and business analysis.
- SQL Server – Data querying, aggregations, CTEs and analytical views.
- Power BI – Interactive dashboards, DAX measures and data visualization.

## Key Performance Indicators
- Total Tasks
- Completed Tasks
- Pending Tasks
- SLA Breach Count
- SLA Compliance Percentage
- Average Turnaround Time (TAT)

## Analysis Performed
1. Data cleaning and validation.
2. Duplicate and missing-value checks.
3. KPI calculations.
4. Team-wise and priority-wise performance analysis.
5. SLA breach investigation.
6. Business insights and recommendations.
7. Interactive Power BI dashboard development.

## Business Insights
The analysis focuses on identifying:
- Teams with higher SLA breach volumes.
- Priority categories requiring operational attention.
- Task status distribution and pending workload.
- Opportunities to improve turnaround time and SLA compliance.

## Recommendations
Recommendations are developed based on the findings to improve task allocation, monitor SLA risks, and strengthen operational performance.

## Project Deliverables
- Excel analysis workbook
- SQL analytical queries
- Power BI interactive dashboard
- Business insights and recommendations
